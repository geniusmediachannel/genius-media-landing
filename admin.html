🎨 Pilihan Model Template Bagian Kustom

Pilih salah satu model template berikut untuk membuat bagian baru dengan preset tata letak siap pakai:

⚡ Media Visual
Model 1: Running Image Marquee
Deretan gambar bergulir terus menerus tanpa jeda. Cocok untuk galeri screenshot, logo klien, dan portofolio.
↔️ Galeri Geser
Model 2: Horizontal Snap Scroll
Galeri kartu gambar lebar yang dapat digeser ke samping secara mulus (snap-scroll), dilengkapi judul & tombol link.
🎴 Grid Interaktif
Model 3: Bento Cards with Buttons
Grid kartu modern dengan gambar preview, badge kategori, teks deskripsi, dan tombol aksi (CTA / WhatsApp).
🖼️ Split CTA
Model 4: Split Showcase Banner
Banner promosi 2 kolom: gambar produk besar di satu sisi berdampingan dengan headline, teks penawaran, dan 2 tombol CTA.
📰 Teks & Editorial
Model 5: Editorial Manifesto & Spotlight Teks
Fokus tulisan deskripsi dan prinsip kerja! Dilengkapi kotak kutipan (*quote box*) beraksen neon dan kartu poin manifesto.
💳 Tabel Paket
Model 6: Tabel Paket Layanan & Harga
3 kolom kartu penawaran harga dengan badge *Best Value*, label harga besar, checklist fitur, dan tombol order WhatsApp.
🗺️ Alur Roadmap
Model 7: Roadmap & Milestone Waktu
Alur linimasa vertikal elegan dengan garis neon dan node tahapan (fase proyek, milestone bisnis, atau rilis versi).
📋 Akordion Fitur
Model 8: Fitur Detail & Accordion Matrix
Daftar rincian fitur / spesifikasi teknis lipat yang dapat diklik pengguna untuk membuka penjelasan mendalam.
