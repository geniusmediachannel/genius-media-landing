🎨 Pilihan Model Template Bagian Kustom

Pilih salah satu model template berikut untuk membuat bagian baru dengan preset tata letak siap pakai:

⚡
Model 1: Running Image Marquee
Deretan gambar bergulir (rolling) terus menerus secara horizontal tanpa jeda. Cocok untuk galeri logo klien, preview screenshot aplikasi, atau foto sertifikat.
↔️
Model 2: Horizontal Snap Scroll
Galeri kartu gambar lebar yang dapat digeser / scroll ke samping secara mulus (snap-scroll), dilengkapi judul, keterangan, dan tombol link.
🎴
Model 3: Bento Cards with Buttons
Grid kartu modern dengan gambar preview, badge kategori, teks deskripsi, dan tombol aksi (Direct Link URL atau Hubungi WhatsApp).
🖼️
Model 4: Split Showcase Banner
Banner promosi 2 kolom: gambar produk besar di satu sisi berdampingan dengan headline, penjelasan penawaran khusus, dan 2 tombol CTA interaktif.
