FAQ

Pertanyaan yang Sering Diajukan

Semua hal yang perlu Anda ketahui sebelum memulai kerja sama pembuatan aplikasi bersama Genius Media Channel.

Apakah source code aplikasi sepenuhnya menjadi milik klien? ▼
Ya, 100%! Setelah pelunasan proyek, seluruh hak cipta dan repository source code (GitHub/GitLab) beserta aset desain diserahkan penuh kepada Anda tanpa adanya vendor lock-in.
Berapa lama rata-rata durasi pengerjaan aplikasi? ▼
Tergantung kompleksitas fitur. Untuk MVP atau sistem berukuran sedang rata-rata memakan waktu 3 sampai 6 minggu, sedangkan sistem enterprise berskala besar berkisar antara 2 sampai 4 bulan dengan sprint mingguan.
Apakah ada garansi setelah aplikasi resmi diluncurkan? ▼
Tentu. Kami memberikan garansi bug-free dan perbaikan teknis gratis selama 30 hingga 90 hari setelah go-live untuk memastikan operasional bisnis Anda berjalan tanpa kendala.
Bagaimana sistem pembayaran untuk proyek custom? ▼
Pembayaran dibagi menjadi termin bertahap berbasis milestone (misal: DP awal 30%, termin progres 40% setelah lolos demo fitur utama, dan pelunasan 30% setelah deployment final).
Apakah Genius Media dapat membantu pengurusan server cloud dan domain? ▼
Ya, kami mendampingi setup infrastruktur server (AWS, GCP, DigitalOcean, Vercel), konfigurasi SSL HTTPS, domain perusahaan, serta akun developer Google Play Store & Apple App Store.
